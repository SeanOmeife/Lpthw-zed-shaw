# Truth Tables
### OR Logic                           AND Logic

| OR              | TRUE   |          | AND             | TRUE   |
|-----------------|--------|          |-----------------|--------|
|True or False    | True   |          | True and False  | False  |
|True or True     | True   |          | True and True   | True   |
|False or True    | True   |          | False and True  | False  |
|False or False   | False  |          | False and False | False  |
