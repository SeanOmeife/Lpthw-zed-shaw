# Truth Tables

### OR Logic

| OR              | TRUE   |          
|-----------------|--------|         
|True or False    | True   |
|True or True     | True   |          
|False or True    | True   |          
|False or False   | False  |          

### AND Logic

| AND             | TRUE   |
|-----------------|--------|
| True and False  | False  |
| True and True   | True   |
| False and True  | False  |
| False and False | False  |
