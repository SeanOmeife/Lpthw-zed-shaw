 Arguments are the actual values or data passed to the function when it is called. The term "arguments" comes from mathematics and logic where it refers to the input values provided to a function or operation.
    This is not to be confused with parameters which are variables defined in the functions declaration to act as a placeholder.

- Method Chaining is a variation of a method call (calling a method on an object) that involves multiple methods being called sequentially on the same object in a single statement. It is referred to in this way because the methods are linked like a chain where the output of one method becomes the input for the next, thereby avoiding the need for immediate variables and making the code more concise

The correct concept is to call a method on a string i.e. print(formatter.format()), where format is the method and formatter is the string. Or simply put...
    command(variable.method())
