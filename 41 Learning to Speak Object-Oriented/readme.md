## Exercise 41 explained
This script is meant to help with memorizing Pyhton Object-Oriented Programming by generating random code snippets and their English descriptions, or vice versa

### How it works
A list of words is downloaded from a website and stored in a list called "WORDS". "PHRASES" is a dictionary that's created with code templates containing placeholders, and their English explanations

The "convert" function replaces placeholders in the code with the description and random words from the list. The script repeatedly shows you either a code snippet or its english description
